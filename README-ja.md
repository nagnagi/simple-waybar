## 特徴 (Features)

- シンプルでミニマルな[Waybar](https://github.com/Alexays/Waybar) のホワイトテーマです。
- ダークテーマの壁紙でも、ホワイトテーマの壁紙にも合いやすいデザインです。
- テキストの後ろにちょっとだけ紫のシャドウを入れています。ちょっとこだわりポイント
- [style.css](https://github.com/nagnagi/simple-waybar/blob/main/style.css) の先頭にカラーを定義しているので、色のカスタマイズが簡単です。

## インストール (Installation)

このコマンドを実行してください。waybarにスタイルが適用されます。

```bash
curl -fsSL https://raw.githubusercontent.com/nagnagi/simple-waybar/main/install.sh | bash
```

実行後、現在の設定のバックアップが自動的に`~/.config/waybar.bkup.(timestamp)`に作成されます。
