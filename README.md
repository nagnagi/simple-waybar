## Features

- A simple and minimal white-themed Waybar.
- Works well with both dark and light wallpapers.
- Features a subtle purple text shadow for a unique touch.
- Colors are defined at the top of [style.css](https://github.com/nagnagi/simple-waybar/blob/main/style.css), making customization easy.

## Installation

Run the following command to apply the theme to Waybar:

```bash
curl -fsSL https://raw.githubusercontent.com/nagnagi/simple-waybar/main/install.sh | bash
```

This will automatically back up your current configuration to ~/.config/waybar.bkup.(timestamp).
